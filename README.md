# NEXVORA

واجهة عربية RTL احترافية لإدارة أكاديمية تعليمية، مع لوحات منفصلة للمدير العام والتشغيل والمتابعة والمدرس والمحاسب.

المسار `/` يعرض الصفحة المناسبة للدور، بينما `/operations` هو مركز العمل اليومي الخاص بمدير التشغيل.

نموذج تفاعلي لإدارة الأكاديميات مبني باستخدام React وTypeScript وVite، ويدعم اتجاه RTL واللغة العربية.

## أهم الوحدات

- صفحات رئيسية منفصلة لمدير التشغيل والمدرس وموظف المتابعة والمحاسب.
- صلاحيات دقيقة على مستوى الشاشة والإجراء ونطاق البيانات.
- إدارة الطلاب والمدرسين والمجموعات والجداول والحضور.
- المدفوعات ومراجعة الإثباتات والمتأخرات وقوالب التواصل.
- التقارير وملخص النظام وسجل النشاط والإشعارات.
- دعم الموبايل والمظهر الداكن والطباعة وتصدير Excel وPDF مباشر.
- أرشفة واستعادة وحذف محلي مؤكد للطلاب، مع منطق حماية للسجلات المرتبطة.
- إنشاء المجموعات ومنع تكرار الاسم وتحديث الإشغال من مصدر حالة واحد.
- Error Boundary وحالات Focus/Hover/Pressed/Disabled واحترام تقليل الحركة.

## التشغيل محليًا

يتطلب المشروع Node.js وpnpm.

```bash
pnpm install
pnpm dev
```

ثم افتح الرابط الذي يظهر في الطرفية، وغالبًا:

```text
http://127.0.0.1:5173/
```

## البناء والاختبارات

```bash
pnpm build
pnpm run test:acceptance
```

تحتوي النسخة الحالية على 36 اختبار قبول وأعمال، تشمل عزل الأدوار ونطاق بيانات المدرس ومنع رفع الصلاحيات وعمليات الأرشفة والاستعادة والحذف وإنشاء المجموعات.

تم كذلك تنفيذ 60 فحص استجابة داخل المتصفح عبر 10 شاشات عند المقاسات 375 و390 و430 و768 و1024 و1440 بكسل دون تدفق أفقي على مستوى الصفحة.

## التصدير

- Excel: ملف XLSX متعدد الأوراق وقابل للفتح.
- PDF: تنزيل مباشر من شاشة ملخص النظام مع دعم العربية وRTL وترقيم الصفحات.
- الطباعة: ما زالت متاحة كخيار مستقل.

الملف التجريبي المتحقق منه موجود في `output/pdf/`.

## ملاحظة

هذا نموذج محلي يعتمد على بيانات تجريبية وLocal Storage، ولا يتصل حاليًا بخادم خلفي أو بوابة دفع أو خدمة رسائل حقيقية.
