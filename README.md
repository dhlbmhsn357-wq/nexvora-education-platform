# NEXVORA

نموذج تفاعلي لإدارة الأكاديميات مبني باستخدام React وTypeScript وVite، ويدعم اتجاه RTL واللغة العربية.

## أهم الوحدات

- صفحات رئيسية منفصلة لمدير التشغيل والمدرس وموظف المتابعة والمحاسب.
- صلاحيات دقيقة على مستوى الشاشة والإجراء ونطاق البيانات.
- إدارة الطلاب والمدرسين والمجموعات والجداول والحضور.
- المدفوعات ومراجعة الإثباتات والمتأخرات وقوالب التواصل.
- التقارير وملخص النظام وسجل النشاط والإشعارات.
- دعم الموبايل والمظهر الداكن والطباعة وتصدير Excel.

## التشغيل محليًا

يتطلب المشروع Node.js وpnpm.

```bash
pnpm install
pnpm dev
```

ثم افتح الرابط الذي يظهر في الطرفية، وغالبًا:

```text
http://127.0.0.1:5173/
```

## البناء والاختبارات

```bash
pnpm build
pnpm run test:acceptance
```

تحتوي النسخة الحالية على 29 اختبار قبول وأعمال، تشمل عزل الأدوار ونطاق بيانات المدرس ومنع رفع الصلاحيات.

## ملاحظة

هذا نموذج محلي يعتمد على بيانات تجريبية وLocal Storage، ولا يتصل حاليًا بخادم خلفي أو بوابة دفع أو خدمة رسائل حقيقية.
